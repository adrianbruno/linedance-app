LineDance App es un proyecto sin fines de lucro distribuido bajo la modalidad copyleft. El objetivo es simple: que los bailarines se concentren en el baile sin preocuparse por la música. El reproductor muestra el nombre de la coreografía, el tema actual y las canciones próximas.

Solo tenés que poner tus archivos MP3 en una carpeta con el formato correcto y dejar que el reproductor haga el resto. El resto de las herramientas son opcionales y están para hacer la experiencia mucho más linda.

                  04

                  Gestor de temas.exe

                  Administrá la lista y descargá audios de YouTube

                  El Gestor permite manejar la lista de reproducción y descargar canciones directamente desde YouTube. Todos los cambios son tomados automáticamente por el Reproductor, incluso mientras está funcionando.

                  🎶 Cola de reproducción

                  Muestra la lista completa de temas. Podés reordenarlos arrastrando, subir o bajar en la lista, o eliminar temas. Para confirmar los cambios presioná «Aplicar orden». Si el Reproductor está activo, también se muestra el tema que está sonando en ese momento.

                  ➕ ABM de temas — Agregar canciones

                  Pegá el link de un video de YouTube y presioná «Cargar». El sistema completa automáticamente el nombre de la canción. Solo resta escribir el nombre de la COREOGRAFÍA y presionar «+ AGREGAR». Repetí el proceso para armar toda la lista a descargar.

                  ⬇ Descarga

                  Toma la lista generada en ABM y descarga los MP3 desde YouTube. Si todo sale bien, los archivos quedan en la carpeta Audios_bajados/.

                  🔄 Preparar

                  Mueve los temas desde Audios_bajados/ hacia audios/ para que el Reproductor los incorpore. Permite editar o confirmar el nombre de la coreografía antes de moverlos.

                  📄 Listar PDF

                  Genera un archivo PDF con el contenido completo de la carpeta audios/. Útil para imprimir y distribuir la lista de canciones y coreografías a los bailarines.

                  05

                  Reproductor.exe

                  Controles de teclado durante la reproducción

                  Una vez que todo está configurado, ejecutá el Reproductor. Controlalo desde el teclado mientras suena la música:

                  ← IzqTema anterior
                  → DerTema siguiente
                  ↑ ArrSubir volumen
                  ↓ AbajBajar volumen
                  EspacioPausar / Reanudar
                  RReiniciar desde el primer tema
                  IReiniciar el tema actual
                  WMostrar QR de control remoto
                  0–9Ir al número de tema escrito
                  LRecargar configuración visual
                  ALT + F4Cerrar el Reproductor
                  06

                  Control remoto

                  Controlá el reproductor desde el celular

                  Presioná W durante la reproducción para ver el código QR. Escanealo con cualquier celular conectado a la misma red WiFi para abrir el control remoto en el navegador.

                  ✓Ver el tema actual con coreografía y canción
                  ✓Controles: anterior, siguiente, play, pausa, detener
                  ✓Barra de progreso con tiempo y duración
                  ✓Control de volumen
                  ✓Búsqueda por número o nombre de tema
                  ✓Lista completa — doble toque para reproducir
                  ✓Múltiples celulares conectados al mismo tiempo
                  ✓Todos ven la misma información en tiempo real
                  ⚙️ Para habilitar el control remoto la primera vez, ejecutá instalar_red.bat como administrador. Configura los permisos de red necesarios para que otros dispositivos puedan conectarse.
